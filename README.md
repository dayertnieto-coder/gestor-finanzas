# 💰 MiFinanza Pro - Gestor de Finanzas Personales

Aplicación web moderna para gestionar tus finanzas personales con gráficos, presupuestos y análisis detallados.

## 🌐 Accede Online
👉 **[Abre MiFinanza Pro](https://tu-url-aqui.netlify.app)**

## ✨ Características

- 📊 Gráficos interactivos (pastel, barras, tendencias)
- 💾 Almacenamiento local (localStorage)
- 🎯 Gestión de presupuestos
- 📱 Responsive (móvil, tablet, desktop)
- 🌙 Tema oscuro/claro
- 📥 Exportar a JSON, PDF y Excel
- 🔐 100% privado (datos locales)

## 🛠️ Tecnologías

- HTML5
- CSS3 (Grid, Flexbox, Animaciones)
- JavaScript ES6+
- Chart.js (Gráficos)
